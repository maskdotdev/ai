# General Test Generation

When asked to generate tests:
- Prioritize behavior-focused tests over implementation details.
- Cover happy path and at least one error/edge case.
- Keep tests readable with clear names.
- Avoid unnecessary mocks.

Produce maintainable pytest tests that pass.
